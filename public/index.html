How it works

  1. Enter the API endpoint you want to probe (e.g. a /me or /profile route).
  2. Paste the cookie string exactly as it appears in your browser's Cookie header.
  3. Enz sends a real request from the server with your cookie attached and inspects the response.
  4. The response is classified as Valid, Bad, Expired, or Unknown.

Verdicts are based on HTTP status, redirect location and well-known response hints (e.g. 401 → bad, 419/440 → expired, body containing "session expired" → expired).
