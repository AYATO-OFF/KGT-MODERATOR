How it works

1

You submit

Enter the API endpoint and a list of cookies. Optional headers, timeout and concurrency are supported.

2

We probe

The server sends one request per cookie (in parallel) with redirects disabled, then reads a bounded snippet of the response.

3

You get verdicts

Each cookie is classified as valid, bad, expired, or error — based on status codes and response heuristics.

HTTP API

POST /api/check
Content-Type: application/json

{
  "endpoint": "https://api.example.com/v1/me",
  "method": "GET",
  "cookies": ["sessionid=abc", "sessionid=def"],
